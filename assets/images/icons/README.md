# Icon mẫu

Thư mục chứa các icon SVG dùng trong nội dung Markdown: `document`, `book`, `trend`, `list`, `check`, `warning` và `decorative`.

```md
![Đã hoàn tất](assets/images/icons/check.svg)
```

Các icon dùng chung `viewBox="0 0 24 24"`, nét `1.5` và tự đổi màu theo chế độ sáng hoặc tối của hệ điều hành.
